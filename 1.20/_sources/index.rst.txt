Qualcomm Cloud AI Documentation
===============================

Qualcomm Cloud AI SDKs (Platform and Apps) enable high performance deep
learning inference on Qualcomm Cloud AI platforms delivering high
throughput and low latency across Computer Vision, Object Detection,
Natural Language Processing and Generative AI models. The SDKs enable end 
to end workflows - from onboarding a pre-trained model to deployment of
the ML inference application in production.
