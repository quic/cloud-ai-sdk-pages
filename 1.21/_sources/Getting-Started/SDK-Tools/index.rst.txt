SDK Tools
=========

Qualcomm Cloud AI Platform and Apps SDKs contain applications and
tools to help the user in every step of the deep learning inference
workflow. The workflow involves taking a trained model through model
conversion, model evaluation (performance, accuracy, etc.), and
deployment in an end-to-end machine learning (ML) application.
