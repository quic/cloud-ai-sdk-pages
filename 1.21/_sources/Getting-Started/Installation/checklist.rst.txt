Local Server Installation
=========================

.. list-table::
   :widths: 10 70 20
   :header-rows: 1

   * -
     - Task
     - Reference
   * - |checkbox|
     - Enable 32 MSIs in BIOS (Intel VT-d or AMD IOMMU)
     - :ref:`MSI Configuration <reference-to-msi>`
   * - |checkbox|
     - Download Platform SDK from QPM
     - :ref:`Download SDKs <reference-to-download-sdks>`
   * - |checkbox|
     - Download Apps SDK from QPM
     - :ref:`Download SDKs <reference-to-download-sdks>`
   * - |checkbox|
     - Install Platform SDK
     - :ref:`Platform SDK <reference-to-platform-sdk>`
   * - |checkbox|
     - Install Apps SDK
     - :ref:`Apps SDK <reference-to-apps-sdk>`
   * - |checkbox|
     - Add user to qaic group
     - See command below
   * - |checkbox|
     - Verify card health
     - :ref:`Verification <reference-to-verification>`

**Add user to qaic group:**

.. code-block:: bash

   sudo usermod -aG qaic $USER
   newgrp qaic  # Apply immediately without logout
